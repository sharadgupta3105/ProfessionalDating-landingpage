Build & Upload Flow

1

Prepare Production Build

npm run build:android-release
2

Sign AAB (Android App Bundle)

Ensure `keystore.jks` is present in `/android/app`. Use release credentials.

3

Console Upload

Production > Create new release > Upload the generated .aab file.
